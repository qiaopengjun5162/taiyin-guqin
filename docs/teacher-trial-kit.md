## 1. 邀请话术（可直接复制）

> 老师您好，我们做了一个古琴减字谱的网页小工具，想请您试用 **10 分钟**，帮我们挑挑毛病。
>
> 打开就能用，什么都不用装：**https://qiaopengjun5162.github.io/taiyin-guqin/**
> （打不开就用备用地址：https://taiyin-guqin-alws.vercel.app/ ）
>
> 现在能用的三件事：
> - 把简谱翻成减字谱，会给几个候选和「为什么这样挪手」的理由；
> - 把打好的谱变成能播放的声音；
> - 导出成图片，或导出成**一行纯文本**（记事本就能传，不依赖装字体）。
>
> 我们最想知道的不是「好不好用」，而是：**您本来会怎么做这件事，我们这条路在哪一步反而比原来麻烦。**
> 小程序版还在做，网页版现在就能用。不方便随时说，不用勉强。

## 2. 请对方试什么（3 件小事，别给压力）

| | 让对方做 | 我们要观察什么 |
|---|---|---|
| **T1** | 打开网页，用键盘点选敲一个减字，或用简谱翻译一小句，看能不能出谱、能不能播 | 从打开到出第一个音卡在哪；有没有「不知道从哪开始」 |
| **T2** | 导出一次（PNG 或减字文本码），自己发到另一个设备 / 发给自己 | 「一行文本就能传」在真实使用中成不成立 |
| **T3** | 说一句：**「我本来会怎么做这件事」** | 我们这条路比原来的办法省在哪、费在哪 —— 这比「挺好用的」有用得多 |

🚩 **刻意不安排「拿老谱拍照识别」**。不是「没验过」，是**已判定结构性失效**：模板索引 257 模板 / 385 文本里 0 条标准完整减字，27 个真实减字覆盖率 0/27（`docs/overview.md:147-165`），对外也明写不报准确率（`docs/pitch.md:223`）。让第一次试用去撞一个已知走不通的入口，等于自己把试用毁掉。

⚠️ **另一个不能承诺的坑**：线上是**纯静态站**，没接后端。`?score=<id>` 直达链接、社区 tab、本机谱迁移这些都要求后端可达（`README.md:191`），现在用不了。所以邀请里只说「导出图片 / 一行文本，自己发出去」，**别说「把谱分享给朋友、对方点开就能看」**。

## 3. 反馈回执（一人一张，照着填）

> 这张表就是「试用记录」。体检清单 **B-3** 的判据是「写了非 0 真实用户却拿不出试用记录」——**填完这张，才算拿得出**。

```
试用回执 · 太音 v0.40.3
日期：
对方身份：  琴馆 / 老师 / 学生 / 其他（可匿名，写清身份即可）
用哪个入口：键盘点选 / 连打 / 简谱翻译 / 没找到 / 别的
设备与浏览器：

T1 出谱 + 播放：        ✅ 走通   /  ⚠️ 卡住   /  ❓ 没找到入口
T2 导出并传到另一处：   ✅ 走通   /  ⚠️ 卡住   /  ❓ 没找到入口
卡住的那一步，对方原话：「                                      」

「我本来会怎么做这件事」：
我们这条路比原来省的地方：
我们这条路比原来费的地方：

愿不愿意再试一次：  愿意 / 再说 / 不用了
如果只能改一件事，最想改：
```

**什么算有效反馈**：能复现的**具体卡点**（哪一步、看到什么、本来以为会怎样）＞「挺好用的」。一句「不知道从哪开始」同样有效——它是 `docs/team-healthcheck.md` **E-9（新手引导）** 唯一的排期依据。

> 本节是**反例引用，不是能力陈述**：左列是「不许说出口的话」，用来对照检查，不代表项目具备该能力。完整红线见 `docs/pitch.md:207-223`；`scripts/verify-publish.mjs:56-63` 另列 6 条机检禁语。
