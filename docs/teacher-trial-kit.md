## 0. 给谁、怎么用（30 秒看完）

| | |
|---|---|
| **给谁** | 要去联系琴馆 / 老师的人（本人或运营同事）。**不需要懂代码**，也不用登服务器、不用拿 AppID。 |

## 1. 邀请话术（可直接复制）

> 老师您好，我们做了一个古琴减字谱的网页小工具，想请您试用 **10 分钟**，帮我们挑挑毛病。
>
> 打开就能用，什么都不用装：**https://qiaopengjun5162.github.io/taiyin-guqin/**
> （打不开就用备用地址：https://taiyin-guqin-alws.vercel.app/ ）
>
> 现在能用的三件事：
> - 把简谱翻成减字谱，会给几个候选和「为什么这样挪手」的理由；
> - 把打好的谱变成能播放的声音；
> - 导出成图片，或导出成**一行纯文本**（记事本就能传，不依赖装字体）。
>
> 我们最想知道的不是「好不好用」，而是：**您本来会怎么做这件事，我们这条路在哪一步反而比原来麻烦。**
> 小程序版还在做，网页版现在就能用。不方便随时说，不用勉强。

### 1.1 微信极简版（最推荐，3 行直接发）

> 老师您好，做了个古琴减字谱的网页小工具，想请您花 10 分钟挑挑毛病，打开就能用、什么都不用装：
> https://qiaopengjun5162.github.io/taiyin-guqin/
> 试完随手回我一句就行：「我本来会怎么做这件事 → 我们这条路在哪一步反而更麻烦」。不方便随时说，不用勉强。

**为什么这么短**：第 1 节那版适合邮件 / 正式邀请；微信里一大段带项目符号，老师多半先看个开头就搁下了。极简版只保留三件事——**能打开的地址、要花多久、回一句什么**。

依据同第 1 节表格：地址见 `docs/overview.md:58,103,209` 与 `README.md:228`；「10 分钟」对应第 2 节 T1~T3 三件小事；「回一句什么」就是第 3.1 节的一句话回执，也就是本文第 1 节邀请原话「您本来会怎么做这件事」与第 2 节 T3 想拿到的东西。**没有新增任何能力承诺。**

## 2. 请对方试什么（3 件小事，别给压力）

| | 让对方做 | 我们要观察什么 |
|---|---|---|
| **T1** | 打开网页（手机或电脑都行），用键盘点选敲一个减字，或用简谱翻译一小句，看能不能出谱、能不能播 | 从打开到出第一个音卡在哪；有没有「不知道从哪开始」 |
| **T2** | 导出一次（PNG 或减字文本码），自己发到另一个设备 / 发给自己 | 「一行文本就能传」在真实使用中成不成立 |
| **T3** | 说一句：**「我本来会怎么做这件事」** | 我们这条路比原来的办法省在哪、费在哪 —— 这比「挺好用的」有用得多 |

🚩 **刻意不安排「拿老谱拍照识别」**。不是「没验过」，是**已判定结构性失效**：模板索引 257 模板 / 385 文本里 0 条标准完整减字，27 个真实减字覆盖率 0/27（`docs/overview.md:147-165`），对外也明写不报准确率（`docs/pitch.md:223`）。让第一次试用去撞一个已知走不通的入口，等于自己把试用毁掉。

⚠️ **另一个不能承诺的坑**：线上是**纯静态站**，没接后端。`?score=<id>` 直达链接、社区 tab、本机谱迁移这些都要求后端可达（`README.md:191`），现在用不了。所以邀请里只说「导出图片 / 一行文本，自己发出去」，**别说「把谱分享给朋友、对方点开就能看」**。

## 3. 反馈回执（一人一张，照着填）

> 这张表就是「试用记录」。体检清单 **B-3** 的判据是「写了非 0 真实用户却拿不出试用记录」——**填完这张，才算拿得出**。

```
试用回执 · 太音 v0.40.3
日期：
对方身份：  琴馆 / 老师 / 学生 / 其他（可匿名，写清身份即可）
用哪个入口：键盘点选 / 连打 / 简谱翻译 / 没找到 / 别的
设备与浏览器：

T1 出谱 + 播放：        ✅ 走通   /  ⚠️ 卡住   /  ❓ 没找到入口
T2 导出并传到另一处：   ✅ 走通   /  ⚠️ 卡住   /  ❓ 没找到入口
卡住的那一步，对方原话：「                                      」

「我本来会怎么做这件事」：
我们这条路比原来省的地方：
我们这条路比原来费的地方：

愿不愿意再试一次：  愿意 / 再说 / 不用了
如果只能改一件事，最想改：
```

### 3.1 一句话回执（对方发微信时用这个）

上面那张表是**项目侧整理用的**，别甩给老师填。微信里只要对方回这一句，就算一份有效记录：

```
「我本来会 ____，试了 ____，卡在 ____（没卡就写没卡）」
```

例如：「我本来是拿笔在纸上划弦位，试了简谱翻译，卡在不知道哪个候选该选」。这一句同时覆盖了 T1 / T3 和「本来会怎么做」，比「挺好用的」有用得多，也不要求对方开电脑、填表、记格式。

### 3.2 发出之后，项目侧怎么记（一行一条）

> 这是给联系的人自己记的流水，**留空是正常的**；有内容才是 E-5 的凭据。

| 日期 | 对方（可匿名） | 怎么发的 | 回没回 | 对方原话（一句话） | 愿意再试 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

**三天没回就这么跟一句**（别连发、别催第二次）：

> 老师打扰一下，上次那个网页链接如果没顾上看就完全没关系～ 要是顺手点开过，哪怕只回一句「没看懂从哪开始」对我们都很帮助。

**硬规矩：发出去 ≠ 有人用了。** 判据仍按第 5 节：至少 1 张填完的回执或 1 条对方原话，才动 `docs/overview.md:85,174,193` 的数字；只填了「怎么发的」不算。

**什么算有效反馈**：能复现的**具体卡点**（哪一步、看到什么、本来以为会怎样）＞「挺好用的」。一句「不知道从哪开始」同样有效——它是 `docs/team-healthcheck.md` **E-9（新手引导）** 唯一的排期依据。
