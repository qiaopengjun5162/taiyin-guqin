## 一、先回答那个一定会被问的问题：这是输入法吗？

**不是。但可以这么说：输入法是我们的三分之一。**

输入法解决的是「*我会弹，我要把指法记下来*」——起点是你脑子里已经有指法。
我们连另外两种更常见的起点也接了：

| 你的起点 | 过去怎么办 | 我们怎么办 |
|---|---|---|
| 脑子里已有指法，只想记下来 | 装软件、装字体、敲字 | 网页上敲（这部分就是输入法，我们也有） |
| 只有一段旋律（简谱 / 别人给的谱 / 自己哼的） | 得自己一个个试指法，试到能弹 | 简谱自动翻成减字，给出候选指法 |
| 只有一张老谱照片或 PDF | 对着图一个字一个字敲 | 整页识别，认出来再逐字校正 |

**一句话定性：我们不是「打字工具」，是「把音乐变成减字谱」的那条产线。**

**两种答法，看对方是谁：**

- 对方没接触过这类工具 → 「不是输入法。输入法是我们的三分之一，我们连『你还没有指法』的情况也接。」
- **对方已经在用某个在线编辑器** → 「也不是编辑器。编辑器要你先把指法想好再敲进去；
  我们的入口是『你还没有指法』——一张照片、一段数字就能进来。」
  （这条要紧：市面上已有同类在线编辑器，且功能比我们全。定位必须落在「入口」，不能落在「编辑器」。）

## 二、三档说法（按场合挑一个）

### 档 1：一句话（电梯里、饭桌上）

> 古琴谱不是音符，是动作指令。我们做的是把音乐翻译成这套动作指令的工具——打开网页就能用，不用装任何东西。

### 档 2：30 秒（别人主动问「你们做什么」）

> 古琴上一个音有一百多种弹法：用哪根弦、按在哪个徽位、哪个手指按、怎么弹。所以古琴谱记的不是音高，是动作，写起来一直是个苦活——过去得装 Windows 软件、装专用字体、还得绑 Office。
>
> 我们把它做成了网页：打开就能写，而且不只是写。给一段简谱，它自动翻成带指法的减字谱；打出来的谱能直接出声，不用琴也能听对不对；要打印、要做课件、要发公众号，一键导出。
>
> 简单说：**编辑器要求你先会弹；查字的工具只告诉你这个字是什么。我们两头都接上——不会弹也能进来，进来出去的是整首能弹能听的谱。**

### 档 3：3 分钟（有耐心听、可能要合作）

**第一段：先讲一个对方不知道的事实。**
古琴一个音有上百种弹法。敲一个简谱「1」，琴上能列出 **134 个位置**——不同弦、不同徽位、不同手指、不同弹法。所以古琴谱（减字谱）本质是**动作编码**，一个方块里塞四个信息。会弹的人读得懂，但想自己记谱、改谱、教别人，就得先会「写」这套编码。

**第二段：讲清楚过去为什么难。**
现在能用的办法只有三种，都不轻松：
- 装 Windows 上的输入法（得改系统字体，Word 里跳字体就乱码）；
- 用手机 App（能写，但只能在手机里，导不出能排版的图）；
- 找高校团队代打（人工，一首要等 3–5 个工作日）。

这两年也有在线编辑器了，浏览器里就能敲，比上面几条都好用。**但它们仍然要求你先会弹**——
你得知道这个音用哪根弦、哪个徽位，才能敲得进去。

所以不管哪一代工具，共同点是同一个：**入口都在「你已经会了」那一侧。**

**第三段：讲我们做了什么。**
同一条链上，从进到出都在一个地方：
1. **进**：敲减字键盘 / 输简谱自动翻译 / 拍一张老谱照片识别；
2. **改**：自动排指法（按「手好不好挪」算，不是随机挑）、查某个音的所有弹法、逐字校正；
3. **听**：整首出声，带节拍器和分句慢练；
4. **出**：整谱可存图 / 打印成 PDF；单个减字可导 PNG 或 SVG（矢量、放大不糊）；另有 WAV 音频、MIDI、纯文本码，直接进课件、公众号、论文谱例。
5. **打开方式**：浏览器，零安装；手机可以「添加到主屏」，装一次之后断网也能开。

**收尾一句**：
> 它不是把某一步做得更漂亮，是把**「你还不会」这个起点也接住了**。

## 三、不比功能，比「入口」

> **2026-11-07 修正。** 原来这里写的是「整条链 vs 单点」，作为最锋利的论证。
> 查证后发现已经有对手（灵弦 lingxian.app）**也是一条链，而且功能比我们全**（五线谱、版本对比、
> 协作、教材、11 种定弦）。所以主论证必须换成**入口论**——它比的是「解决哪个问题」，不是「功能多少」。
> 原有论证不作废，但只对第一代对手成立。

### 3.1 对第一代对手（火蜘蛛 / 丝桐里）：单点 vs 一条链

> 别家是**单点工具**：负责「写」的不管「出声」，负责「排版」的不管「指法」，文件之间靠人搬。
> 我们是**同一条链**：减字、简谱、音高、播放、导出用同一份数据，能互转、不会对不上。

只对这两家成立。**遇到用在线编辑器的对手，别用这句，会被当场反问。**

### 3.2 对新一代对手（在线编辑器）：编辑器 vs 入口

> 编辑器都要求你**先把指法想好**——它的起点是「你敲」。
> 我们的起点是「**你还没有指法**」：一张老谱照片，或一段简谱数字。

收口两句，挑一句说：

> 编辑器解决「我已经会了，怎么记下来」。我们解决「我还不会，怎么开始」。
> 前者是**效率**问题，后者是**门槛**问题。门槛更靠前。

### 3.3 为什么这句最抗追问

因为它在**换问题**，不是在比答案。对方说「你功能比他少」，你不辩解功能，而是举一个他确实做不到的
具体例子：**把一张老谱照片放进去，出来一份能播、能改、能转简谱的谱**。
他的编辑器要你先敲，我们的入口允许你什么都不懂。

## 四、四条真优势 + 两条要认的差距

### 4.1 真的只有我们有（四条，可放心讲）

| | 说明 | 对手现状 |
|---|---|---|
| **老谱照片 → 整首结构化指法** | 识别的输出是弦/徽/指法/音高，所以**能播、能改、能转简谱、能导 MIDI** | 在线编辑器没有识别（路线图最后一阶段才做）；查字类（爱搜减字 2015 / 华夏古琴网 2021）只做**单字**检索，输出是释义和视频，**不产出谱**；AI 释谱（2021）做的是**字形级**——输出印刷用的谱，不能播 |
| **谱例溯源 → 当场试听** | 这个字在哪些曲子里出现过：曲名 + 第几句 + 第几音，点一下直接出声 | 查字工具（爱搜减字）有「出处」，但那是**图片索引**，只能看到哪一页、听不了；我们没有第二家 |
| **减字文本码** | 一串 `ad9f6cg4` 就是一句减字，粘贴到哪都能还原成谱 | **人可读、可手打的文本码，产品里没见到第二家**。但「编码 + 组合出百万级字符」早有：2008 年丁晓君等有表达式与自造字库，2015 年包松平输入法已「组合输出数百万字」。真实差别只在**载体**（我们 ASCII，他们 PUA 字库）——见 `competitive-analysis.md` 18.6 / 二十章 |
| **纯前端、无账号、可离线** | 数据在自己电脑，断网能开 | 对手都是云端 SaaS，要账号、要订阅 |

### 4.2 我们细一点，但别夸大成「只有我们」

- **简谱自动翻减字**：在线编辑器也有，同样给候选和取舍理由。
  我们的差别是**理由来自代价表**——能解释「为什么这样挪手更省力」，不是随机挑一个。
  **这是深度差异，不是有无差异。**
- **播放**：对**编辑器 / 在线 SaaS**（丝桐里、灵弦），我们多出分句慢练与节拍器。
  但对**练习类 app** 来说这套是及格线——2018 年的丝桐（iOS，免费）就有琴面等比例图、
  A/B 句循环、0.5 倍延音、录音回放。**它不是差异点，是入场券**（见 `competitive-analysis.md` 第十九章）。

### 4.3 必须认的差距（不辩解，换问题）

没有五线谱对照 · 没有版本对比/回滚 · 没有多人协作 · 定弦只有 3 种（灵弦 11 种、爱搜减字音位图 16 种）。

> 被问到时**不要解释为什么没做**，直接换问题：
> 「那些是编辑器要解决的问题。我们解决的是编辑器前面那一步——谱还没成形的时候，怎么进来。」

**例外：字库覆盖这条不能「换问题」，只能认。**

包松平古琴减字输入法 2015 年就自述：基础指法减字**近 1500 个**（**含异体字与上古声曲折谱符**）、
指法名称用字近 500 个、手势/琴体/音律图 200 多个，组合输出「数百万字」，
**「已基本覆盖《琴曲集成》全 30 册」**。

我们的实际存量（`apps/web/scripts/inventory-glyphs.ts` 现场数出来的）：字体 **471 个字形**、
SVG 降级 **45 个部件**；**异体字和上古声曲折谱符一个都没有**；覆盖范围从来没统计过。
最扎人的数字是最后一项：**内置 4 首谱加起来只用到 27 个不同的减字**——那就是目前全部实测覆盖。

被问「你这字全不全」，正确答法是：

> 「常见指法都能打。罕见的异体字、上古声曲折谱符现在没有；具体覆盖多少，我们还没数过——正在数。」

**别说「全」，也别说「理论上无限」。** 前者会被当场对谱，后者是架构话术不是答案（详见 `competitive-analysis.md` 第二十章）。

## 五、对方会拿什么反驳你（含新一代）

| 他会想 | 死穴在哪 |
|---|---|
| 「我装个输入法不就行了」 | 只能 Windows；要改系统字体，Word 里一换字体就乱码；只负责「写」，不出声、不排版 |
| 「我下个 App」 | 在 App 里写的东西导不出能排版的图；订阅制；没有识别，老谱还是得手敲 |
| 「找人代打」 | 人工，一首 3–5 个工作日；改一稿再等一轮；沟通成本比打谱本身还高 |
| 「我自己在 Word 里拼」 | 慢、不标准、不能播、发给别人还得让对方也装字体 |
| **「我已经在用在线编辑器了」** | 那是编辑器，**得你先会弹**。你手上那张老谱照片，它进不去——它要你从零敲 |
| **「AI 释谱不是也能识别吗」** | 它识别的是**字形**，输出是拿去印的谱；不能播、不能改、不能转简谱。而且那是 2021 年的出版定制项目，不是随手能用的工具 |
| **「分句慢练、琴面图这些我早就有」** | 对，2018 年的丝桐（免费 iOS）就有琴面等比例图、A/B 句、0.5 倍延音、录音回放。**那是入场券，我们没打算当卖点**。我卖的是它们在的那个位置——你手里那张老谱照片，它进不去 |

> 一句收口：**前面四个都能「写出来」，但没有一个能「用起来」；
> 后两个能「用起来」，但要你自己先会。**

## 六、对不同的人，重点不一样

**对弹琴的人（琴友、学生）**
> 你手上那段简谱，不用自己一个个试指法了。敲进去，它给你几种排法，你挑顺手的；挑完能直接听，不用上琴就知道对不对。

**对琴馆老师 / 做课件的人**
> 你手里的老谱、教材，能变成可播放的减字谱，导出 PNG / SVG 直接进课件，矢量图放大不糊；要音频就导 WAV。以前是「找人打谱 + 找人排版」两件事，现在一件。

**对高校 / 院系（论文谱例、打谱项目）**
> 现在人工打谱的公开基准是 3–5 个工作日出成品。我们的起点不是「从零敲」，是「拍图识别 + 校正」——省掉的是最枯燥的那一段，不是准确度。

**对技术背景的人**
> 核心全部编译成 WASM 跑在浏览器里，纯前端、零后端，所以能离线、能部署成静态站；减字渲染是字体连字为主、SVG 四象限兜底的双层，字体拼不出的生僻组合也不会散架。

## 七、红线速查（这几句千万别说）

| 别说 | 为什么 | 该怎么说 |
|---|---|---|
| 「AI 识别减字谱」 | 实测让大模型直接认，准确率 **0%**；可用的是模板匹配 | 「拍照识别，认出来再逐字校正」 |
| 「识别准确率 100%」 | 整页识别是 best-effort，小字号明显下降 | 「字大一点识别很稳，小字建议逐字校对」 |
| 「小程序已上线」 | 壳已做好，但**未发布、未上真机**验证 | 「小程序版在做，网页版现在就能用」 |
| 「只有我们能做」 | 已经有人在做（含高校团队），且随时可能有人做出识别 | 「我们现在能做到这一步」 |
| **「没人做过减字编码」** | 1989 年陈长林就在《计算机学报》发过，2008 年丁晓君等在《中国音乐学》给出了表达式（`大*七*六+注挑*七`）+ 分析树 + 自造字库 + 可编辑软件，2010 年代还有专利。这是查得到原文的公开学术史 | 「编码早就有人做，但都要先装他的字库；我们的谱是一行文本，记事本就能传」 |
| **「没人做过减字识别」** | **2015 年爱搜减字就做手写查字、2021 年华夏古琴网小程序做拍照查字，都免费。**古琴圈很小，这句话一出口就会被纠正，还会把「整页识别」这个真优势一起赔掉 | 「单字查字早就有人做了，它们停在『这个字什么意思』；我们做的是**整页 → 能弹能听的整首谱**」 |
| 「只有我们有简谱转减字」 | **2026-09 已上线一家在线编辑器（灵弦），同样有候选和取舍理由** | 「都有。我们的理由是算出来的，能解释为什么这样挪手」 |
| 「AI 识别减字谱是我们的」 | 中央音乐学院团队 2021 年就发布过「AI 释谱」，做字形级识别 | 「我们是把识别的结果变成能播能改的指法数据」 |
| 「我们是最好的减字谱编辑器」 | 论编辑器功能我们缺五线谱/版本/协作/教材，**硬拼会输** | 「我们不是编辑器，是编辑器的入口」 |
| 「比别家快 N 倍」 | 没有实测数据 | 「人工基准是 3–5 个工作日，我们的起点是识别不是从零敲」 |
| 「AI 会自动排指法」 | 排指法是确定性算法（按手部位移算最优），不是 AI | 「自动排指法，按手好不好挪来算」 |
| **「我们字库很全 / 什么古谱都能打」** | 包松平 2015 就有近 1500 基础减字（**含异体字与上古声曲折谱符**）、覆盖《琴曲集成》30 册；我们 471 字形 + 45 部件，**异体字一个都没有，覆盖没统计过**。古琴圈有人能拿一本《琴曲集成》逐页对 | 「常见指法都能打；异体字和古谱异形还没有，覆盖范围我们正在数」 |

## 八、最好用的收尾（如果对方只打算记住一句）

> **编辑器要你先会弹。我们让你还不会的时候就能进来。**

如果对方是上一代工具的用户（装字体、装输入法那批），换成这句：

> **古琴谱的输入法只管「打字」。我们管「从一张谱，到能弹、能听、能发出去」的全过程——而且打开网页就能用，什么都不用装。**
