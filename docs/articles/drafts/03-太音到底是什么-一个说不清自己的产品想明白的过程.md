## 一、一句说不清自己的产品

做「太音」的第十一个月，我被一句话问住了：

**「这个产品到底是什么？」**

我答过很多个版本。「把音乐翻译成动作指令的工具」「古琴谱的翻译器」「减字谱智能拼装平台」——每一句都是真的，但每一句说完，对方还是要再问一遍。

最扎心的对比来自一个现成的例子：**「AI 释谱」**。人家四个字，所有人都懂。我们说了三分钟，别人还是一脸「所以呢？」

这篇文章就记这件事：**一个产品怎么花了一年学会介绍自己**。中间有四个被推翻的判断、三版被否掉的介绍词，和一个最后想明白的道理。先讲过程，再讲它到底是什么。

---

## 二、先说背景：古琴谱为什么需要「打谱」

古琴谱（减字谱）记的不是音符，是**动作指令**：哪根弦、按第几徽、哪个手指、怎么弹。一个方块字里塞四个信息。会弹的人读得懂；不会弹的人对着一本谱，一个字也用不上。

把这样的谱变成能弹的音乐，琴人叫**「打谱」**——行话「小曲打三月，大曲打三年」，说的就是这活。过去想拿到一首能弹的曲子，只有三条路：

| 办法 | 代价 |
|---|---|
| 找老师一句一句教 | 一首学几个月 |
| 找人代打 | 一首 3–5 个工作日，改一稿再等一轮 |
| 自己一个字一个字敲进电脑 | 装 Windows 软件、装专用字体，换台电脑就乱码 |

太音想做的事就一件：**把这一步的门槛拆掉**——照着谱子把减字敲进网页，或传一份简谱让它自动排指法，出来一份能弹、能听、能改的谱。

## 三、过程一：四个「独有」，四个都被推翻

产品做到一定阶段，手里自然攒了一堆「我们有别人没有」的清单。2026 年 11 月的一天，四篇公众号文章连续打脸，一天之内清单清零：

| 我们以为 | 实际上 |
|---|---|
| 「不会弹也能进」这个入口是我们独有的 | 2015 年的「爱搜减字」就有手写/拍照查字，免费 |
| 「减字文本码」是独有载体 | 2008 年厦大的论文就有表达式编码 + 自造字库，还申请了专利 |
| 慢练、分句是差异点 | 2018 年的「丝桐」app 早有琴面图、A-B 句、0.5 倍速延音 |
| 字库很全 | 2015 年有人整理过 1500 个减字（含异体字），覆盖《琴曲集成》30 册 |

**减字谱数字化从 1989 年就开始了。** 三十七年里，几乎每个功能点上都有前人。在功能表里找「独有」，是条死路。

那还剩什么？剩**位置**：

> 不争「第一个做」，争「入口 × 出口」的组合——入口是「你还不会的时候就能进来」，出口是「出去的不是一张图，是一首能弹的曲子」。

（这也是「太音」和只做单字查询的工具、只做编辑器的工具，位置上的差别。）

## 四、过程二：三版介绍词，两版被否

定位清楚了，话还是说不清。介绍词迭代了三轮：

**第一版（讲原理）**：「古琴谱不是音符，是动作指令。我们做的是把音乐翻译成这套动作指令的工具。」
——被否。原理没错，但对方得先听懂「动作指令」这个词。

**第二版（讲场景）**：「古琴谱的翻译器——老谱拍张照、逐字校对一遍，出来是能弹、能听的曲子。」
——还是被否。原话：「还是不好啊……『AI 释谱』就很好理解，那我们太音到底是什么？」

**第三版（讲行话）**：

> **太音 = 古琴打谱工具。像「AI 释谱」帮你读懂谱那样，太音帮你把谱弹出来。**

这次成了。想明白的道理只有一条：

**用行话命名，名字本身就是解释。**

「AI 释谱」好懂，不是因为「AI」，是因为「释谱」是琴人现成的词。我们前两版的「动作指令」「翻译器」「智能拼装」，都是自己造的新词——对方要先听懂词，才能听懂产品。而「打谱」这个词，琴人圈里天天说，不用解释。

顺手把门面上「AI 驱动」的角标也撤了。实测让大模型直接认减字，准确率是 0%（它把三十多个不同的字都答成了同一个）；当时在干活的是模板匹配。「AI」写在门面上，就是超口径。（后来 11 月 9 日又查明：模板匹配认的是字体里的复合指法符号，对真实减字谱同样不成立，见第六节。）

## 五、所以，太音到底是什么

**一句话：古琴打谱工具——把看不懂的老谱，变成能弹的曲子。**

「AI 释谱」的终点是**看懂**（输出印出来的谱）；太音的终点是**弹出**（输出能弹、能听、能改、能发出去的谱）。

从哪进都行，三条路：

- **你还不会弹，手里有老谱** → 用连打键盘照谱敲入，或传一份简谱自动排指法，出来一份能弹能听的谱；图片录入目前仅作干净电子谱面的辅助，且结果必须逐格校正；
- **你会弹，想打谱、整理、出教材** → 敲键盘（连打 `ad9f6cg4` 就是「大九六分绰勾四」）或传简谱，自动排指法，出图、出声、出文本码；
- **你已经在学** → 逐句慢练、节拍器、调音器、跟弹判定、日课记录。

出去也有四种形态：**图**（PNG / 矢量 SVG / PDF）、**声**（播放 / WAV / MIDI）、**码**（一行纯文本，记事本就能发给琴友）、**谱**（转成简谱，给只看得懂简谱的人）。

不用装软件、不用装字体——网页打开就用，手机电脑都行，断了网也能开。

## 六、数字与诚实

| | 数字 |
|---|---|
| 代码 | 约 5 万行（Rust 核心 + 前端） |
| 测试 | 1,555 条 |
| 版本 | v0.39.9 |
| 真实用户 | **0** |

图片录入，必须说清楚：那组「72px 下 100%、48px 下 97.6%、24px 下 59.5%」的数字，测的是**识别器自己的 257 个复合指法符号**、用同一套字体合成的图，不是真实减字谱。2026-11-09 判定又查明：模板库里一条标准完整减字（如「大九勾四」）都没有，识别单元和真实谱面根本对不上——**不是准确率高低，是这条路目前走不通**。所以现阶段的入口是键盘打谱和简谱翻译；图片只作干净电子谱面的录入辅助，且必须逐格校正。

## 七、下一步：不补功能，出门

工具做了一年，产品一直在路上。想明白「是什么」之后，计划反而变简单了：

1. 小程序真机验证 → 发布（用户在微信里，入口就该在微信里）；
2. 这篇文章发出去，找 3 个琴馆 / 老师试用；
3. 识别不再按「补功能」排期——结构性问题已判定清楚，等真有人提出「我要扫老谱」再评估。

从现在起立一条规矩：**新功能不按「竞品有什么」排期，按「用户用不用得上」排期。**

- 你**会弹**、受够了装字体装软件的打谱流程——来试第二段路；
- 你**在学琴**——慢练和日课给你用。
