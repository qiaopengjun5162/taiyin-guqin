## 2. 内容骨架（全文六节）

| 节 | 核心内容 |
|---|---|
| 演奏姿势 | 坐凳宜高琴桌宜低、鼻对四五徽之间；两腕虚悬不靠琴面；初学指头不可离弦（挑七弦靠六弦） |
| 基本指法 | 右手八法「抹挑勾剔打摘托劈」、左手四法「吟猱绰注」；按弦取音分甲音/肉音/甲肉相半（四五徽以上用甲、七徽以下用肉） |
| 学琴三要 | 树雄心（难学易忘不中听，须发宏愿）/ 贵钻研（曲高和寡靠钻研破）/ 重专精（一曲未精勿及二曲） |
| 弹琴五谬五能 | 五谬：头足摇动、妄肆瞻视、错乱中辍、精神散慢、下指疎懒；五能：坐安、视专、意闲、神鲜、指坚 |
| 下指六忌 | 折指、以指助用力、纯用甲出煞声、跪按不雅、腕靠琴面等六个坏习惯 |
| 操缦十四法 | 和、坚、松、脆、清、洁、润、幽、轻、重、疾、徐、亮、采（前八论音质，后六论力度速度与丰神） |

## 3. 可引用点（短引，引用必须带出处）

- 「弹欲断弦方为妙」（右手八法）/「按令入木乃称奇」（左手四法）——琴人常说的弹按要诀出处
- 「欲修妙音者，必先修妙指」（操缦十四法·洁）
- 十四法之「徐」：「古人以琴涵养性情，故名其声曰『希声』」——与《大音希声》文本线同源
- 「一曲未精，遽及二曲，二曲未熟，更及三曲，以至毕生不能精练一曲」（学琴三要·重专精）
