# 2026-10-30 · 用字形模板匹配把识别从 0% 救到 100%，并接进后端识别端点

## 1. 意图

42 条字体真字上视觉大模型 exact_match = 0%（模板坍缩、在背提示词示例），识别功能
等于不可用。按上一轮定下的出路②落地「电子谱面走非视觉路径」——让识别真正能用。

## 4. 卡点与解决

- **现象一**：加椒盐噪声后命中率 78.6%，且 0.5%/1%/2% 三档**完全相同**。
- **误判**：以为中值滤波没起作用。
- **定位过程**：三档同值 → 不是噪声强度问题，是共同机制。打印归一化中间量发现：
  噪点把背景翻黑 → 墨迹外接框被撑到整图 → 字形被缩小进角落。
- **根因**：椒盐噪声的「翻转」会制造远离字形的孤立墨点，外接框裁剪对它零抵抗力。
- **改法**：归一化第一步加 3x3 中值滤波（干净图上近乎恒等）→ 0.5% 回 100%、
  1% 97.6%、2% 92.9%。去斑是必需预处理，不是可选项。

- **现象二**：Rust 单测「平移不变性」红了，但调试打印的两张归一化结果肉眼一致。
- **误判**：以为实现有浮点/越界 bug。
- **定位过程**：打印中值滤波后的平滑图 → 发现 4x4 小方块的**角被腐蚀成菱形**，
  而第二张图的方块贴着画布下边缘，边缘钳位让它少掉两个角 → 两图形状本就不同。
- **根因**：测试写错了。3x3 中值滤波的边缘钳位是滤波固有性质，贴边墨块的腐蚀
  形状与不贴边的不同——「平移不变」测试的前提（同一形状）被自己破坏了。
- **改法**：测试改为两张都不贴边的墨块（diff 0）；并把这条性质写进测试注释。
  **测试失败时先怀疑观测手段和测试本身，再怀疑实现。**

## 5. 结论与可引用点

- 同一批 42 条字体真字：视觉大模型 exact **0%**，模板匹配 exact **100%**，
  CER 1.193 → **0.000**，单张 1.4s 计费 → **<1ms 零成本**。
- 端到端（HTTP 真链路）复测 42/42，与离线逐位一致；置信度（top-2 margin 比）
  [0.8,1.0) 桶 42/42——**这是真的可信置信度**，不像视觉模型那样高置信度全错。
- 诚实边界（扰动实验量化）：平移/缩放/模糊全 100%，椒盐噪声 2% 起掉到 92.9%；
  且全部是「同一字体渲染」分布，拍照/扫描件不适用，走 auto 模式自动落 LLM。
- 可引用句：「识别准确率 0% 的问题不在管线、不在提示词，而是问题本身问错了对象——
  电子谱面不需要『看懂』，只需要『认出』；认出是查表，不是理解。」
